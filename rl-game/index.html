The Canvasser: a reinforcement learning game

You are a canvasser with 20 moves before the polls close. Two houses hold supporters who haven't voted yet; two hold people who already voted. Step onto a house to knock (each house once per game). Then let a Q-learning agent learn the same game from nothing but the reward numbers.

You're playing. Use the arrow keys or the buttons.

How the game works. Walking into the edge of the map wastes a move. The game ends when the 20 moves run out or when all four doors have been knocked. The agent sees only its position (25 squares) and which of the 4 houses it has knocked (2⁴ = 16 combinations): 25 × 16 = 400 states, 4 moves each, so its table has 1,600 numbers. It does not see the clock.

2. The reward function

These numbers are all the agent ever learns from. Every move earns the sum of the parts that apply. Changes take effect right away for both you and the agent; press Reset agent to retrain from scratch under the new numbers.

3. The Q-learning agent

Explores randomly 20% of the time (ε = 0.2), learning rate α = 0.2, discount γ = 0.95, all Q-values start at 0, ties are broken at random, and the random numbers come from a fixed seed, so pressing the same buttons in the same order always gives the same results.

4. Learning curve

Each point summarizes a block of 50 training games (exploration included). Top: the average reward the agent collected. Bottom: the share of those games that met the real goal, reaching both unvoted supporters before the polls closed. Both panels share the same horizontal axis.
